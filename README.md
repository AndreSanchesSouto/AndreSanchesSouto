## 👨‍💻 Sobre Mim

<div align="center">
  <img align="right" src="https://media.giphy.com/media/SWoSkN6DxTszqIKEqv/giphy.gif" width="300" alt="GIF de programador" />
</div>

Sou um **Desenvolvedor Full-Stack** apaixonado por construir soluções robustas, escaláveis e inteligentes. Atualmente atuo como **Desenvolvedor (Bolsista) no Instituto de Tecnologia do Paraná (TECPAR)**, onde combino engenharia de software com IA e automação para resolver problemas do mundo real.

### 🚀 O que eu faço

- 🔄 **Automação e Integração** — Construindo fluxos de trabalho com **n8n**, integrações de APIs e conexões com bancos de dados
- 🤖 **Inteligência Artificial** — Desenvolvendo soluções com IA usando **OpenAI API**, **RAG**, **Embeddings** e automação inteligente
- 📊 **Business Intelligence** — Criando plataformas de BI e **Mapas de Calor** interativos com HTML, CSS e JavaScript
- 🌐 **Desenvolvimento Web** — Criando aplicações web modernas, de alta performance, com arquitetura limpa e excelente UX
